# docs/accord — what Accord is, for an AI working in this repo

Start with `AGENTS.md` at the repo root (identical to `CLAUDE.md`); it gives the reading order. This folder holds what an AI needs and cannot fetch from inside a sandbox:

- `spec-hgff4jxe-2026-09-23.md` — Mike's spec, with the nine asks and his answers. Snapshot; the live document `https://proof.vpsmikewolf.duckdns.org/d/hgff4jxe` is canonical.
- `layout-6ybuxh8e-2026-09-23.md` — Ren's layout proposal, ruled Yes to all twelve. Snapshot of `/d/6ybuxh8e`.
- `rulings.md` — Mike's rulings in date order with sources, the standing gates, and what is not to be started.

To refresh a snapshot, the reviewer runs the export on the VPS (the access token stays there; see `~/Projects/_estate/bin/ask-mike` for the transport) and replaces the file with a new date in its name.
